# 轻量持久化与管理员权限 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不改排产算法的前提下，用 SQLite 持久化人工业务操作，并用单管理员短期会话保护所有修改接口。

**Architecture:** Excel 继续作为原始业务数据，`scheduler/persistence.py` 作为独立覆盖层保存操作日志和会话摘要。FastAPI 启动时加载 Excel 后重放有效操作；前端通过 `backend-bridge.js` 统一携带 bearer token，原有页面结构保持不变。

**Tech Stack:** Python 3.13、标准库 `sqlite3` / `hashlib` / `secrets` / `hmac`、FastAPI、原生 JavaScript、pytest。

**Spec:** `backend/docs/superpowers/specs/2026-09-22-轻量持久化与管理员权限-design.md`

## Global Constraints

- 不修改 `backend/scheduler/engine.py` 的目标函数、约束与排产规则。
- 默认数据库固定为 `backend/runtime/scheduler.db`，可由 `SCHEDULER_DB_PATH` 覆盖。
- 管理员密码只从 `SCHEDULER_ADMIN_PASSWORD` 读取，不写入文件、数据库或日志。
- 未配置管理员密码时，GET 只读接口正常，所有修改接口返回 `503 admin_not_configured`。
- token 默认有效期 8 小时，只在数据库保存 SHA-256 摘要。
- 每个修改操作必须先校验，再在 SQLite 事务内保存；数据库失败不能修改正式内存状态。
- 原始 Excel 与历史甘特图 JSON 的存储方式保持不变。
- 每个任务单独提交，可从标签 `before-persistence-auth-20260922` 回滚。

## Review Focus

- 同一个正式急单请求因网络重试到达两次时，只能生成一条有效操作记录；Task 5 增加幂等测试。
- token 在请求处理中恰好过期时必须拒绝修改且不能产生数据库记录；Task 2 增加边界测试。
- SQLite 被锁定或磁盘写入失败时，正式内存状态必须保持原样；Task 1 和 Task 3 增加回滚测试。
- 某条历史操作 payload 损坏时，启动恢复必须报告该条告警并继续恢复其他有效记录；Task 3 增加损坏记录测试。
- 前端收到 401 后重新登录并重试时，表单内容必须保留且只提交一次；Task 6 增加浏览器契约测试。

```python
class OperationStore:
    def __init__(self, path: Path):
        self.path = Path(path)
        self.path.parent.mkdir(parents=True, exist_ok=True)
        self._initialize()

    def connect(self):
        conn = sqlite3.connect(self.path, timeout=5)
        conn.row_factory = sqlite3.Row
        conn.execute('PRAGMA journal_mode=WAL')
        conn.execute('PRAGMA foreign_keys=ON')
        conn.execute('PRAGMA busy_timeout=5000')
        return conn
```

建表字段严格使用设计文档中的 `operations`、`admin_sessions`、`schema_meta`。

```sql
  reverts_operation_id TEXT REFERENCES operations(id)

CREATE TABLE admin_sessions (
  token_hash TEXT PRIMARY KEY,
  created_at TEXT NOT NULL,
  expires_at TEXT NOT NULL,

CREATE TABLE schema_meta (version INTEGER NOT NULL);
```

