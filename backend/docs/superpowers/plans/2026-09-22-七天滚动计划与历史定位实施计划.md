# 七天滚动计划与历史定位实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** 将正式甘特窗口改为七天，并以月份、周计划、周内版本三级结构定位历史排程。

**Architecture:** 调度仍计算订单完整生产链与自身交期，presenter 只截取七天正式甘特窗口。历史存储按排产基准推导七天周期和周内修订号，摘要接口支持月份过滤；前端按需加载月份并用三个选择器定位版本。

**Tech Stack:** Python、FastAPI、pytest、原生 JavaScript/HTML/CSS。

**Spec:** `docs/superpowers/specs/2026-09-22-七天滚动计划与历史定位-design.md`

## Global Constraints

- 订单交期、全量求解和剩余工序计算不因七天显示窗口截断。
- 周周期从 2026-08-03 00:00 起连续划分。
- 历史查看只读，后台刷新不得覆盖。
- 旧快照自动补齐周归属，不删除。

## Review Focus

- 8月3日前创建的迁移数据归入首周，不产生负周号。
- 跨月周按开始日期归属月份。
- 同一周多版本修订号稳定递增。
- 月份无记录时不出现空周选项。
- 快速切换月份或版本时最后一次操作生效。
