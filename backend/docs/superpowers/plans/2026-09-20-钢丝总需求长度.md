# 钢丝总需求长度 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将拉丝排程从成品长度改为外层钢丝总需求长度，并保留芯不排产规则。

**Architecture:** `Spec` 负责可靠解析外层钢丝根数；桥接层将成品长度转换为钢丝总长度；引擎和紧急度估计使用该长度，再以产品额定表的 m/s 计算时间。无法识别的结构不猜测。

**Tech Stack:** Python 3、pytest、pandas。

**Spec:** `docs/superpowers/specs/2026-09-20-钢丝总需求长度-design.md`

## Global Constraints

- 拉丝速度只使用《产品额定（平均值）》中的 m/s 原值。
- 不得引入重量、密度或丝径换算。
- IWRC、FC 不进入本厂三道工序排程。
- 捻制长度系数固定使用现有 `LAY_FACTOR=1.03`。

## Review Focus

- `6*19S+FC` 必须得到 114 根外层钢丝，FC 不得增加根数。
- `8*K26WS+IWRC` 必须得到 208 根外层钢丝，IWRC 不得增加根数。
- 拉丝工时必须使用钢丝总长度，而非成品长度。
- 无单股丝数的结构不得被默认为一根钢丝。
- 紧急度最短工时与实际排程必须使用同一钢丝总长度。

```python
@property
def outer_wire_count(self) -> int | None:
    match = re.match(r'^(\d+)', self.struct_key)
    return self.strands * int(match.group(1)) if match else None

def wire_requirement_m(spec, finished_rope_m):
    count = spec.outer_wire_count
    if count is None:
        raise ValueError('规格缺少单股丝数')
    return finished_rope_m * count * C.LAY_FACTOR
```
