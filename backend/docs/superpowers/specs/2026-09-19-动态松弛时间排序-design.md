# 动态松弛时间排序设计

## 目标

在不改变工艺、设备、人工锁定与P0优先规则的前提下，将普通订单从仅按交期排序升级为按剩余松弛时间排序，并与现有结果进行全量对比。

## 方案

对每张可排订单估算最快完整工艺链时间：拉丝、捻股、合绳加工时间之和，加两次最小工序交接时间。承诺截止取原始预发货日加企业已确认的延期容忍小时数。

`松弛时间 = 承诺截止 - 排程基准 - 最快完整工艺链时间`

排序键依次为：人工P0、松弛时间升序、原始预发货日升序、数量降序。积压订单继续单独统计，但参与同样的松弛度计算。缺少匹配产能的订单保持人工队列，不虚构工时。

## 边界

- 本轮只验证动态松弛时间排序的直接效果，不引入全局优化器。
- 延期只改变承诺截止，不改变严格准时评价。
- 加工时间来自现有设备速度与工艺桥接参数，仍属于待企业校准数据。
- 结果必须通过完整工序链、设备不重叠、交接2至72小时等现有硬约束校验。

## 验收

- 单元测试证明长加工订单在同交期下松弛时间更小。
- P0始终排在非P0之前。
- 全量测试通过。
- 输出与原EDD试算的覆盖率、准时订单数、超期订单数和实际计划终点对比。
