# 排产算法方法论说明

> 用途：评审答辩「技术方案」与「算法选型」章节的讲稿底稿。
> 一句话立场：**我们刻意不做黑盒最优化，但不是不做优化——我们做的是"可解释的最优化"，并且把最优性差距量化给评委看。**

---

## 一、问题是什么

把排产问题翻译成厂里能听懂的话：**109 台机器（车位）× 323 张订单（车），每张订单必须依次经过拉丝 → 捻股 → 合绳三道工序，换规格要停机 1–5 小时打扫。**

数学上这叫「带顺序依赖换型的柔性作业车间调度问题」（FJSP with sequence-dependent setup）：

- 同一张订单的三道工序有**严格先后约束**（R6：交接 ≥2h）
- 换型时间取决于**上一张订单的规格**（顺序依赖，不是固定值）
- 一道工序可有多台机器胜任（柔性），但速率不同
- 目标不是单一目标：**违约损失 → 准时率 → 容忍窗履约 → 利用率均衡 → 稳定性**（字典序多目标）

这类问题是 **NP-hard**。323 张订单的组合数量远超宇宙原子总数，**不存在能在可接受时间内求出全局最优的算法**——这是数学性质，不是工程能力问题。

## 二、当前做法：批次化分层字典序启发式

（实现：`scheduler/engine.py`，约 480 行）

**流程**：订单按「优先档位 → 交期 EDD → 数量」排序 → 逐单拆批（单批目标 24h，≤12 批）→ 合绳 JIT 贴交期倒排 → 捻股必须「合绳开工前 ≥2h 完工」→ 拉丝必须「捻股开工前 ≥2h 完工」→ 赶不上则下游整链级联顺延 → 按字典序选机（JIT：换型最小 → 负荷均衡；ASAP：最早完工优先）→ 门禁判定准时/超期。

**它的性质要说清楚**：

| 维度 | 表现 |
|---|---|
| 求解速度 | 14 秒完成 323 单 × 3 工序（6789 条批次任务） |
| 可解释性 | 每条任务带 `constraint_trace`，指回 R1–R10 具体约束与影响 |
| 人工可干预 | 优先档位调整、插单、停机、物料延迟均即时重排并给前后 KPI 对比 |
| **最优性** | **无保证**。逐单贪心、选中不回退，属「局部最优的堆叠」，不等于全局最优 |

**诚实结论**：现在的解是「好且说得清」的解，不是「最好」的解。准时率偏低的成因中，数据侧（165 单先天积压、9 月交期挤兑、拉丝瓶颈 88.9%）是主因，但**贪心缺少回退能力**也是实打实的损失来源。

## 三、为什么不做黑盒最优化（评审硬性项）

赛题明确：**「约束可解释 + 人工可干预」占 15%，黑盒排产直接 0 分**。同时企业现场的诉求是：

1. 排产结果必须能回答「为什么排这台机、为什么这时候」
2. 调度员必须能推翻算法的决定，且系统要告诉他推翻的代价
3. 换型、交接、优先级的规则改动要能立刻生效，不需要重新训练模型

因此我们的技术路线是**规则驱动 + 全链路留痕**，而不是「丢给模型自己学」。

## 四、可解释的最优化：三层改进路线

关键认知：**可解释 ≠ 不能优化**。下面三层全部是白盒的，每一步改进都能说出"把哪批从哪台机挪到哪台机，KPI 变了多少"。

### ① 快速启发式（已实现）
规则驱动快速给出可行解，14 秒完成全量排产，每条任务可追溯。解决「有没有」的问题。

### ② 局部改进 / 邻域搜索（下一步，性价比最高）
在①的结果上做**改善式搜索**，只接受让目标函数变好的移动，迭代到收敛：

- **换机邻域**：把瓶颈工序（拉丝）某批次从当前机台移到另一台候选机
- **换序邻域**：同一机台上相邻两批次交换顺序（可能减少一次换型）
- **合并/拆批邻域**：调整批次数，减少换型次数或改善交付节奏
- **换型聚类**：把同规格/近似规格的批次排在一起，批量摊薄换型

每次移动都记录：*「订单 JW-0821-23 拉丝批 6 从 8170 移至 8192，减少换型 2h，交期提前 1.5 天，全厂准时率 +0.3%」*——**优化过程本身就是可解释的**。

### ③ 小规模精确求解（最优性差距量化）
用 CP-SAT（OR-Tools）对**单工序或 ≤20 单子集**求全局最优，作为启发式的下界对照：

- 输出：「在 20 单子集上，精确最优的准时率为 X%，我们的启发式达到 Y%，**最优性差距 Z%**」
- 价值：把"我们的解好不好"从主观判断变成**可量化指标**，这是答辩技术分最有说服力的一页

### ④ 多目标 Pareto 前沿（可选加分）
把字典序目标改为加权标量化，扫描权重得到「准时率 vs 利用率」的权衡曲线，让决策者按偏好选点（交期优先 / 省机器优先），而不是被算法单方面决定。

## 五、答辩话术（三句话版本）

1. **「为什么不用遗传算法/强化学习？」** —— 赛题硬性要求可解释与人工可干预，黑盒 0 分；且换型规则天天变，规则驱动比模型重训更贴合现场。
2. **「那你们是不是没做优化？」** —— 做了，且分三层：快速启发式给出可解释好解（14 秒），局部搜索持续改进（每次挪动都有留痕），CP-SAT 小规模精确对照量化最优性差距。
3. **「准时率为什么只有 3.2%？」** —— 这是数据体检的结果，不是算法的失败：165 单在排产基准日前就已逾期（历史欠账），叠加 9 月交期挤兑与拉丝产能瓶颈（88.9% 负荷）。算法如实报告并把每单延期原因标注到可干预的粒度，这正是我们主张的"先讲真话，再谈优化"。

## 六、边界与风险（主动交底）

- 桥接推断（绳结构 → 股结构 → 股径 → 丝径）全部标黄，需企业确认后方可作为正式依据；
- 订单表无客户字段，R8 罚款客户、R9 重点订单无法自动识别，设计为人工标注；
- 局部搜索是启发式改善，仍不保证全局最优——但可给出改进幅度与收敛曲线，让评审看到"离最优有多远"。
